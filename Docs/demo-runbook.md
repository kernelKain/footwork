# Demo runbook

Use this order for a 60-second demonstration. The backup video, hero screenshot, and mobile screenshot are not in the repository. Add those files before treating the demonstration as complete. Prepared playback is the labeled example. It is not a live generation.

## First ten seconds

1. Open https://footwork-m6g0.onrender.com/.
2. Show the heading "Turn a walk into music."
3. Move to "Hear what a moment does" and point at the turn, then the pause. Say that a corner is meant to change the melody's direction and a pause is meant to become a break.

## Show the prepared example

1. Choose **Hear an example**. The studio opens on "Corner and pause."
2. The page says "Example walk" and "This sound is an example made in the browser. It is not a studio recording."
3. Press **Play**. One control drives the route, the ribbon, and the current moment.
4. Seek the turn near 0:18 and the pause near 0:36. Say that these marks are planned illustrations in the example.

Do not say this press called Gemma or Eleven.

## If a live walk is available

Use a walk that has already been reviewed. Do not start a new generation during the demo unless the day's provider budget still has room. A new piece spends one Gemma attempt and, when the plan validates, one music attempt.

If generation is slow or unavailable, return to **Hear an example** and say the live studio path fell back. A Route Sketch is the simpler version made from the walk. It is not a studio recording.

## What not to claim

- The example was generated during the presentation.
- A planned musical change has been heard in a studio file, unless the heard-time sheet in `Docs/evidence/seed-walk-review.md` is filled.
- The route on screen is a map. It is an abstracted shape and contains no coordinates.
